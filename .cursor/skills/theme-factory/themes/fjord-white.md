# Fjord White

Nordic Creative Studio’s own system. Cool white, signal blue, and a geometric display face — not a dark remake of Stadga.

## Color Palette

- **Paper**: `#f5f8fc` - App background
- **White**: `#ffffff` - Surfaces
- **Navy**: `#0b1f44` - Headlines
- **Blue**: `#1d5eff` - Actions
- **Ice**: `#e8eef8` - Soft bands
- **Ink**: `#10203a` - Body text

## Typography

- **Headers**: Syne
- **Body Text**: Plus Jakarta Sans
- **Figures**: JetBrains Mono

## Best Used For

Creative SaaS, product studios, and tools that should feel like software — not a ledger.
